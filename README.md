# Archivo Galáctico

Aplicación React para explorar naves del universo de Star Wars con datos de [SWAPI](https://swapi.py4e.com/). Permite buscar por nombre y clase, consultar especificaciones y pilotos, y guardar una flota personal en este navegador.

## Desarrollo

```sh
npm install
npm run dev
```

## Producción

```sh
npm run build
npm run preview
```
